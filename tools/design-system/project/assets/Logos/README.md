# Logos

Kelpie's logo, copied from `docs/brand/` (drawn by `scripts/brand-icons.mjs`; ADR-0049). The ink is `accent` (#0A7469 light, #3BC3AE in the dark lockup); a tile is `accent` with the mark in `on-accent` (#F0FAF8).

- `kelpie-mark.svg`: the mark alone, Master's mascot as a silhouette, with round ears.
- `kelpie-lockup-light.svg` and `kelpie-lockup-dark.svg`: the mark beside "Kelpie" in Bricolage Grotesque 680, for light and dark grounds.
- `favicon-16.svg`: the 16 px favicon master, an `accent` tile with the mark on whole pixels.
- `app-icon.svg`, `app-icon-rounded.svg` and `app-icon-maskable.svg`: the sources of the home-screen icons.

Use the logo only as the brand, never in place of an agent's mascot, never in `warm`, and with nothing within half a cap of the lockup.
